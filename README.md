# Rob Reider — Political Voiceover Landing Page

Vite-based, responsive landing page using the supplied headshot and political demo reel.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build for production

```bash
npm run build
npm run preview
```

## Before launch

1. Replace `YOUR-EMAIL-HERE@example.com` in `src/main.js` with Rob's real booking email.
2. Add his confirmed studio/remote-session specifications in the "Professional Studio" section.
3. Replace or supplement the current meta tags with the final production domain.
4. If desired, add analytics and a form endpoint.

The demo reel is stored at:
`public/audio/rob-reider-political-demo.mp3`

The headshot is stored at:
`public/images/rob-reider-headshot.jpg`
